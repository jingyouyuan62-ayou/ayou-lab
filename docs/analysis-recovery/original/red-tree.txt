## 1. Red Tree

实际画面是**从下往上看的树冠**：深色、盘曲的枝干交织成网，绿色羽状叶（像松柏针叶），成簇的鲜红小花/果实点缀其间，背景是米色天空。整体被压平成一张图案，很像屏风画或印染布。

- composition：满构图、无单一焦点；枝条从四周向中间交织
- color：米色底 #E8E3D2、近黑枝干 #2A2E28、灰绿 #7A8A72、鲜红点缀 #D8442E

- texture：平面图案感，红色呈细密点状
- material：纸、织物、屏风画
- spatialDepth：几乎没有纵深，被压平
- hierarchy：枝干骨架 → 红色簇点 → 绿叶 → 米色底
- mood：繁盛、古典、装饰性、略带神秘
- visualStyle：图案化植物画
- interaction：作为背景纹理平铺、局部放大、缓慢漂移
